## Common Questions & Answers

### For Students
**Q: Where can I find all the math symbols?**  
A: Right panel of dashboard (desktop) or bottom tab (mobile). See [COMPACT_UI_QUICK_START.md#symbol-categories](COMPACT_UI_QUICK_START.md).

**Q: How do I use a symbol in my proof?**  
A: See Symbol Library section in [COMPACT_UI_QUICK_START.md#quick-actions](COMPACT_UI_QUICK_START.md).

**Q: What's the ≡ button that appears sometimes?**  
A: That's the theme toggle for dark mode. See [COMPACT_UI_QUICK_START.md#to-toggle-dark-mode](COMPACT_UI_QUICK_START.md).

### For Developers
**Q: How is the 3-column layout implemented?**  
A: CSS Grid in `compact-dashboard.css`. Details at [COMPACT_UI_TECHNICAL_ARCHITECTURE.md#grid-structure](COMPACT_UI_TECHNICAL_ARCHITECTURE.md).

**Q: Where's the symbol database?**  
A: In `compact-symbol-library.js`, `initializeSymbols()` method. See [COMPACT_UI_TECHNICAL_ARCHITECTURE.md#symbol-data-structure](COMPACT_UI_TECHNICAL_ARCHITECTURE.md).

**Q: How does dark mode work?**  
A: CSS variables that change based on `theme-dark` class. See [COMPACT_UI_TECHNICAL_ARCHITECTURE.md#dark-mode-integration](COMPACT_UI_TECHNICAL_ARCHITECTURE.md).

### For QA Teams
**Q: Where's the test checklist?**  
A: [TESTING_AND_VERIFICATION_GUIDE.md](TESTING_AND_VERIFICATION_GUIDE.md) - 40+ tests organized by category.

**Q: What's the success criteria?**  
A: See [TESTING_AND_VERIFICATION_GUIDE.md#summary-report](TESTING_AND_VERIFICATION_GUIDE.md).

### For DevOps
**Q: What files need to be deployed?**  
A: See [DEPLOYMENT_AND_INTEGRATION_CHECKLIST.md#step-1-pre-deployment-verification](DEPLOYMENT_AND_INTEGRATION_CHECKLIST.md).

**Q: What if something goes wrong?**  
A: See [DEPLOYMENT_AND_INTEGRATION_CHECKLIST.md#rollback-procedures](DEPLOYMENT_AND_INTEGRATION_CHECKLIST.md).
