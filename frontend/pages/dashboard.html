💡 Tips for Success

1. Start Simple

Begin with basic limit proofs before tackling advanced theorems. Build your foundation first!

2. Use Keyboard Shortcuts

Press Alt+key to insert symbols (e.g., Alt+e for ε). Hover over symbol buttons to see shortcuts.

3. Ask for Strategy First

Click "Suggest Proof Strategy" before writing. Understanding the approach helps you learn better.

4. Verify Each Step

Use the "Verify" button on each proof step. Learn from feedback to improve your reasoning.

5. Don't Rush

AI responses take 20-60 seconds for detailed proofs. Patience leads to better explanations!
